Sahih Muslim · Book 56

Hadith 7556

حَجَّاجُ بْنُ الشَّاعِرِ ← عَبْدُ الصَّمَدِ بْنُ عَبْدِ الْوَارِثِ ← أَبِي ← حُسَيْنٌ ← قَتَادَةَ ← عَبْدِ اللَّهِ بْنِ مَعْبَدٍ الزِّمَّانِيِّ ← عَبْدِ اللَّهِ بْنِ عُتْبَةَ ← عَبْدِ اللَّهِ بْنِ مَسْعُودٍ { أُولَئِكَ الَّذِينَ يَدْعُونَ يَبْتَغُونَ إِلَى رَبِّهِمُ الْوَسِيلَةَ} قَالَ نَزَلَتْ فِي نَفَرٍ مِنَ الْعَرَبِ كَانُوا يَعْبُدُونَ نَفَرًا مِنَ الْجِنِّ فَأَسْلَمَ الْجِنِّيُّونَ وَالإِنْسُ الَّذِينَ كَانُوا يَعْبُدُونَهُمْ لاَ يَشْعُرُونَ فَنَزَلَتْ { أُولَئِكَ الَّذِينَ يَدْعُونَ يَبْتَغُونَ إِلَى رَبِّهِمُ الْوَسِيلَةَ}
