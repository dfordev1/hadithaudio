Sunan Abi Dawud · Book 27

Hadith 3671

مُسَدَّدٌ ← يَحْيَى ← سُفْيَانَ ← عَطَاءُ بْنُ السَّائِبِ ← أَبِي عَبْدِ الرَّحْمَنِ السُّلَمِيِّ ← عَلِيِّ بْنِ أَبِي طَالِبٍ عَلَيْهِ السَّلاَمُ أَنَّ رَجُلاً، مِنَ الأَنْصَارِ دَعَاهُ وَعَبْدَ الرَّحْمَنِ بْنَ عَوْفٍ فَسَقَاهُمَا قَبْلَ أَنْ تُحَرَّمَ الْخَمْرُ فَأَمَّهُمْ عَلِيٌّ فِي الْمَغْرِبِ فَقَرَأَ { قُلْ يَا أَيُّهَا الْكَافِرُونَ } فَخَلَطَ فِيهَا فَنَزَلَتْ { لاَ تَقْرَبُوا الصَّلاَةَ وَأَنْتُمْ سُكَارَى حَتَّى تَعْلَمُوا مَا تَقُولُونَ } .
