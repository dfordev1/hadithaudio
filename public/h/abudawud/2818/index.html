Sunan Abi Dawud · Book 16

Hadith 2818

مُحَمَّدُ بْنُ كَثِيرٍ ← إِسْرَائِيلُ ← سِمَاكٌ ← عِكْرِمَةَ ← ابْنِ عَبَّاسٍ فِي قَوْلِهِ { وَإِنَّ الشَّيَاطِينَ لَيُوحُونَ إِلَى أَوْلِيَائِهِمْ } يَقُولُونَ مَا ذَبَحَ اللَّهُ فَلاَ تَأْكُلُوا وَمَا ذَبَحْتُمْ أَنْتُمْ فَكُلُوا فَأَنْزَلَ اللَّهُ عَزَّ وَجَلَّ { وَلاَ تَأْكُلُوا مِمَّا لَمْ يُذْكَرِ اسْمُ اللَّهِ عَلَيْهِ } .
