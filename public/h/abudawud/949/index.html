Sunan Abi Dawud · Book 2

Hadith 949

مُحَمَّدُ بْنُ عِيسَى ← هُشَيْمٌ ← إِسْمَاعِيلُ بْنُ أَبِي خَالِدٍ ← الْحَارِثِ بْنِ شُبَيْلٍ ← أَبِي عَمْرٍو الشَّيْبَانِيِّ ← زَيْدِ بْنِ أَرْقَمَ كَانَ أَحَدُنَا يُكَلِّمُ الرَّجُلَ إِلَى جَنْبِهِ فِي الصَّلاَةِ فَنَزَلَتْ { وَقُومُوا لِلَّهِ قَانِتِينَ } فَأُمِرْنَا بِالسُّكُوتِ وَنُهِينَا عَنِ الْكَلاَمِ .
