Sunan Abi Dawud · Book 19

Hadith 2922

هَارُونُ بْنُ عَبْدِ اللَّهِ ← أَبُو أُسَامَةَ ← إِدْرِيسُ بْنُ يَزِيدَ ← طَلْحَةُ بْنُ مُصَرِّفٍ ← سَعِيدِ بْنِ جُبَيْرٍ ← ابْنِ عَبَّاسٍ فِي قَوْلِهِ { وَالَّذِينَ عَقَدَتْ أَيْمَانُكُمْ فَآتُوهُمْ نَصِيبَهُمْ } قَالَ كَانَ الْمُهَاجِرُونَ حِينَ قَدِمُوا الْمَدِينَةَ تُوَرِّثُ الأَنْصَارَ دُونَ ذَوِي رَحِمِهِ لِلأُخُوَّةِ الَّتِي آخَى رَسُولُ اللَّهِ صلى الله عليه وسلم بَيْنَهُمْ فَلَمَّا نَزَلَتْ هَذِهِ الآيَةُ { وَلِكُلٍّ جَعَلْنَا مَوَالِيَ مِمَّا تَرَكَ } قَالَ نَسَخَتْهَا { وَالَّذِينَ عَقَدَتْ أَيْمَانُكُمْ فَآتُوهُمْ نَصِيبَهُمْ } مِنَ النُّصْرَةِ وَالنَّصِيحَةِ وَالرِّفَادَةِ وَيُوصِي لَهُ وَقَدْ ذَهَبَ الْمِيرَاثُ .
