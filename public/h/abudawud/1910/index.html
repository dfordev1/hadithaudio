Sunan Abi Dawud · Book 11

Hadith 1910

هَنَّادٌ ← أَبِي مُعَاوِيَةَ ← هِشَامِ بْنِ عُرْوَةَ ← أَبِيهِ ← عَائِشَةَ تْ كَانَتْ قُرَيْشٌ وَمَنْ دَانَ دِينَهَا يَقِفُونَ بِالْمُزْدَلِفَةِ وَكَانُوا يُسَمَّوْنَ الْحُمْسَ وَكَانَ سَائِرُ الْعَرَبِ يَقِفُونَ بِعَرَفَةَ قَالَتْ فَلَمَّا جَاءَ الإِسْلاَمُ أَمَرَ اللَّهُ تَعَالَى نَبِيَّهُ صلى الله عليه وسلم أَنْ يَأْتِيَ عَرَفَاتٍ فَيَقِفَ بِهَا ثُمَّ يُفِيضَ مِنْهَا فَذَلِكَ قَوْلُهُ تَعَالَى { ثُمَّ أَفِيضُوا مِنْ حَيْثُ أَفَاضَ النَّاسُ } .
