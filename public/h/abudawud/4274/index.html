Sunan Abi Dawud · Book 37

Hadith 4274

أَحْمَدُ بْنُ إِبْرَاهِيمَ ← حَجَّاجٌ ← ابْنِ جُرَيْجٍ ← يَعْلَى ← سَعِيدِ بْنِ جُبَيْرٍ ← ابْنِ عَبَّاسٍ فِي هَذِهِ الْقِصَّةِ فِي { الَّذِينَ لاَ يَدْعُونَ مَعَ اللَّهِ إِلَهًا آخَرَ } أَهْلُ الشِّرْكِ قَالَ وَنَزَلَ { يَا عِبَادِيَ الَّذِينَ أَسْرَفُوا عَلَى أَنْفُسِهِمْ } .
