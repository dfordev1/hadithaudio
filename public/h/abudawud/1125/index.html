Sunan Abi Dawud · Book 2

Hadith 1125

مُسَدَّدٌ ← يَحْيَى بْنِ سَعِيدٍ ← شُعْبَةَ ← مَعْبَدِ بْنِ خَالِدٍ ← زَيْدِ بْنِ عُقْبَةَ ← سَمُرَةَ بْنِ جُنْدُبٍ ← رَسُولَ اللَّهِ صلى الله عليه وسلم كَانَ يَقْرَأُ فِي صَلاَةِ الْجُمُعَةِ { سَبِّحِ اسْمَ رَبِّكَ الأَعْلَى } وَ { هَلْ أَتَاكَ حَدِيثُ الْغَاشِيَةِ } .
