Sunan Abi Dawud · Book 34

Hadith 4101

مُحَمَّدُ بْنُ عُبَيْدٍ ← مُحَمَّدُ بْنُ ثَوْرٍ ← مَعْمَرٍ ← ابْنِ خُثَيْمٍ ← صَفِيَّةَ بِنْتِ شَيْبَةَ ← أُمِّ سَلَمَةَ تْ لَمَّا نَزَلَتْ { يُدْنِينَ عَلَيْهِنَّ مِنْ جَلاَبِيبِهِنَّ } خَرَجَ نِسَاءُ الأَنْصَارِ كَأَنَّ عَلَى رُءُوسِهِنَّ الْغِرْبَانُ مِنَ الأَكْسِيَةِ .
