Sunan Abi Dawud · Book 32

Hadith 3974

مُحَمَّدُ بْنُ عِيسَى ← سُفْيَانُ ← عَمْرُو بْنُ دِينَارٍ ← عَطَاءٍ ← ابْنِ عَبَّاسٍ لَحِقَ الْمُسْلِمُونَ رَجُلاً فِي غُنَيْمَةٍ لَهُ فَقَالَ السَّلاَمُ عَلَيْكُمْ فَقَتَلُوهُ وَأَخَذُوا تِلْكَ الْغُنَيْمَةَ فَنَزَلَتْ { وَلاَ تَقُولُوا لِمَنْ أَلْقَى إِلَيْكُمُ السَّلاَمَ لَسْتَ مُؤْمِنًا تَبْتَغُونَ عَرَضَ الْحَيَاةِ الدُّنْيَا } تِلْكَ الْغُنَيْمَةَ .
