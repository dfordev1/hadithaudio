Sunan Abi Dawud · Book 32

Hadith 3985

مُحَمَّدُ بْنُ عَبْدِ الرَّحْمَنِ أَبُو عَبْدِ اللَّهِ الْعَنْبَرِيُّ ← أُمَيَّةُ بْنُ خَالِدٍ ← أَبُو الْجَارِيَةِ الْعَبْدِيُّ ← شُعْبَةَ ← أَبِي إِسْحَاقَ ← سَعِيدِ بْنِ جُبَيْرٍ ← ابْنِ عَبَّاسٍ ← أُبَىِّ بْنِ كَعْبٍ ← النَّبِيِّ صلى الله عليه وسلم أَنَّهُ قَرَأَهَا { قَدْ بَلَغْتَ مِنْ لَدُنِّي } وَثَقَّلَهَا .
