Sunan Abi Dawud · Book 15

Hadith 2646

أَبُو تَوْبَةَ الرَّبِيعُ بْنُ نَافِعٍ ← ابْنُ الْمُبَارَكِ ← جَرِيرِ بْنِ حَازِمٍ ← الزُّبَيْرِ بْنِ خِرِّيتٍ ← عِكْرِمَةَ ← ابْنِ عَبَّاسٍ نَزَلَتْ { إِنْ يَكُنْ مِنْكُمْ عِشْرُونَ صَابِرُونَ يَغْلِبُوا مِائَتَيْنِ } فَشَقَّ ذَلِكَ عَلَى الْمُسْلِمِينَ حِينَ فَرَضَ اللَّهُ عَلَيْهِمْ أَنْ لاَ يَفِرَّ وَاحِدٌ مِنْ عَشَرَةٍ ثُمَّ إِنَّهُ جَاءَ تَخْفِيفٌ فَقَالَ { الآنَ خَفَّفَ اللَّهُ عَنْكُمْ } قَرَأَ أَبُو تَوْبَةَ إِلَى قَوْلِهِ { يَغْلِبُوا مِائَتَيْنِ } قَالَ فَلَمَّا خَفَّفَ اللَّهُ تَعَالَى عَنْهُمْ مِنَ الْعِدَّةِ نَقَصَ مِنَ الصَّبْرِ بِقَدْرِ مَا خَفَّفَ عَنْهُمْ .
