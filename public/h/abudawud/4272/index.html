Sunan Abi Dawud · Book 37

Hadith 4272

مُسْلِمُ بْنُ إِبْرَاهِيمَ ← حَمَّادٌ ← عَبْدُ الرَّحْمَنِ بْنُ إِسْحَاقَ ← أَبِي الزِّنَادِ ← مُجَالِدِ بْنِ عَوْفٍ ← خَارِجَةَ بْنَ زَيْدٍ سَمِعْتُ زَيْدَ بْنَ ثَابِتٍ، فِي هَذَا الْمَكَانِ يَقُولُ أُنْزِلَتْ هَذِهِ الآيَةُ { وَمَنْ يَقْتُلْ مُؤْمِنًا مُتَعَمِّدًا فَجَزَاؤُهُ جَهَنَّمُ خَالِدًا فِيهَا } بَعْدَ الَّتِي فِي الْفُرْقَانِ { وَالَّذِينَ لاَ يَدْعُونَ مَعَ اللَّهِ إِلَهًا آخَرَ وَلاَ يَقْتُلُونَ النَّفْسَ الَّتِي حَرَّمَ اللَّهُ إِلاَّ بِالْحَقِّ } بِسِتَّةِ أَشْهُرٍ .
