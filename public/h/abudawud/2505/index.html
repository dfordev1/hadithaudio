Sunan Abi Dawud · Book 15

Hadith 2505

أَحْمَدُ بْنُ مُحَمَّدٍ الْمَرْوَزِيُّ ← عَلِيُّ بْنُ الْحُسَيْنِ ← أَبِيهِ ← يَزِيدَ النَّحْوِيِّ ← عِكْرِمَةَ ← ابْنِ عَبَّاسٍ { إِلاَّ تَنْفِرُوا يُعَذِّبْكُمْ عَذَابًا أَلِيمًا } وَ { مَا كَانَ لأَهْلِ الْمَدِينَةِ } إِلَى قَوْلِهِ { يَعْمَلُونَ } نَسَخَتْهَا الآيَةُ الَّتِي تَلِيهَا { وَمَا كَانَ الْمُؤْمِنُونَ لِيَنْفِرُوا كَافَّةً }
