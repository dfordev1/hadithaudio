Sunan Abi Dawud · Book 18

Hadith 2869

أَحْمَدُ بْنُ مُحَمَّدٍ الْمَرْوَزِيُّ ← عَلِيُّ بْنُ حُسَيْنِ بْنِ وَاقِدٍ ← أَبِيهِ ← يَزِيدَ النَّحْوِيِّ ← عِكْرِمَةَ ← ابْنِ عَبَّاسٍ { إِنْ تَرَكَ خَيْرًا الْوَصِيَّةُ لِلْوَالِدَيْنِ وَالأَقْرَبِينَ } فَكَانَتِ الْوَصِيَّةُ كَذَلِكَ حَتَّى نَسَخَتْهَا آيَةُ الْمِيرَاثِ .
