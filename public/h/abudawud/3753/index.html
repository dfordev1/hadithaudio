Sunan Abi Dawud · Book 28

Hadith 3753

أَحْمَدُ بْنُ مُحَمَّدٍ الْمَرْوَزِيُّ ← عَلِيُّ بْنُ الْحُسَيْنِ بْنِ وَاقِدٍ ← أَبِيهِ ← يَزِيدَ النَّحْوِيِّ ← عِكْرِمَةَ ← ابْنِ عَبَّاسٍ { لاَ تَأْكُلُوا أَمْوَالَكُمْ بَيْنَكُمْ بِالْبَاطِلِ إِلاَّ أَنْ تَكُونَ تِجَارَةً عَنْ تَرَاضٍ مِنْكُمْ } فَكَانَ الرَّجُلُ يُحْرَجُ أَنْ يَأْكُلَ عِنْدَ أَحَدٍ مِنَ النَّاسِ بَعْدَ مَا نَزَلَتْ هَذِهِ الآيَةُ فَنَسَخَ ذَلِكَ الآيَةُ الَّتِي فِي النُّورِ قَالَ { لَيْسَ عَلَيْكُمْ جُنَاحٌ } { أَنْ تَأْكُلُوا مِنْ بُيُوتِكُمْ } إِلَى قَوْلِهِ { أَشْتَاتًا } كَانَ الرَّجُلُ الْغَنِيُّ يَدْعُو الرَّجُلَ مِنْ أَهْلِهِ إِلَى الطَّعَامِ قَالَ إِنِّي لأَجَّنَّحُ أَنْ آكُلَ مِنْهُ . وَالتَّجَنُّحُ الْحَرَجُ وَيَقُولُ الْمِسْكِينُ أَحَقُّ بِهِ مِنِّي . فَأُحِ
