Sunan Abi Dawud · Book 5

Hadith 1259

أَحْمَدُ بْنُ يُونُسَ ← زُهَيْرٌ ← عُثْمَانُ بْنُ حَكِيمٍ ← سَعِيدُ بْنُ يَسَارٍ ← عَبْدِ اللَّهِ بْنِ عَبَّاسٍ ← كَثِيرًا مِمَّا كَانَ يَقْرَأُ رَسُولُ اللَّهِ صلى الله عليه وسلم فِي رَكْعَتَىِ الْفَجْرِ بِـ { آمَنَّا بِاللَّهِ وَمَا أُنْزِلَ إِلَيْنَا } هَذِهِ الآيَةَ قَالَ هَذِهِ فِي الرَّكْعَةِ الأُولَى وَفِي الرَّكْعَةِ الآخِرَةِ بِـ { آمَنَّا بِاللَّهِ وَاشْهَدْ بِأَنَّا مُسْلِمُونَ } .
