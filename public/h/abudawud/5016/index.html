Sunan Abi Dawud · Book 43

Hadith 5016

أَحْمَدُ بْنُ مُحَمَّدٍ الْمَرْوَزِيُّ ← عَلِيُّ بْنُ حُسَيْنٍ ← أَبِيهِ ← يَزِيدَ النَّحْوِيِّ ← عِكْرِمَةَ ← ابْنِ عَبَّاسٍ { وَالشُّعَرَاءُ يَتَّبِعُهُمُ الْغَاوُونَ } فَنَسَخَ مِنْ ذَلِكَ وَاسْتَثْنَى فَقَالَ { إِلاَّ الَّذِينَ آمَنُوا وَعَمِلُوا الصَّالِحَاتِ وَذَكَرُوا اللَّهَ كَثِيرًا } .
