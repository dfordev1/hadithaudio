Sunan Abi Dawud · Book 2

Hadith 500

مُسَدَّدٌ ← الْحَارِثُ بْنُ عُبَيْدٍ ← مُحَمَّدِ بْنِ عَبْدِ الْمَلِكِ بْنِ أَبِي مَحْذُورَةَ ← أَبِيهِ ← جَدِّهِ قُلْتُ يَا رَسُولَ اللَّهِ عَلِّمْنِي سُنَّةَ الأَذَانِ . قَالَ فَمَسَحَ مُقَدَّمَ رَأْسِي وَقَالَ " تَقُولُ اللَّهُ أَكْبَرُ اللَّهُ أَكْبَرُ اللَّهُ أَكْبَرُ اللَّهُ أَكْبَرُ تَرْفَعُ بِهَا صَوْتَكَ ثُمَّ تَقُولُ أَشْهَدُ أَنْ لاَ إِلَهَ إِلاَّ اللَّهُ أَشْهَدُ أَنْ لاَ إِلَهَ إِلاَّ اللَّهُ أَشْهَدُ أَنَّ مُحَمَّدًا رَسُولُ اللَّهِ أَشْهَدُ أَنَّ مُحَمَّدًا رَسُولُ اللَّهِ تَخْفِضُ بِهَا صَوْتَكَ ثُمَّ تَرْفَعُ صَوْتَكَ بِالشَّهَادَةِ أَشْهَدُ أَنْ لاَ إِلَهَ إِلاَّ اللَّهُ أَشْهَدُ أَنْ لاَ إِلَهَ إِلاَّ اللَّهُ أَشْهَدُ أَنَّ مُحَمَّدًا رَسُولُ اللَّهِ أَشْهَدُ أَنَّ مُحَمَّ
