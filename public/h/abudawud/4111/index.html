Sunan Abi Dawud · Book 34

Hadith 4111

أَحْمَدُ بْنُ مُحَمَّدٍ الْمَرْوَزِيُّ ← عَلِيُّ بْنُ الْحُسَيْنِ بْنِ وَاقِدٍ ← أَبِيهِ ← يَزِيدَ النَّحْوِيِّ ← عِكْرِمَةَ ← ابْنِ عَبَّاسٍ { وَقُلْ لِلْمُؤْمِنَاتِ يَغْضُضْنَ مِنْ أَبْصَارِهِنَّ } الآيَةَ فَنُسِخَ وَاسْتُثْنِيَ مِنْ ذَلِكَ { وَالْقَوَاعِدُ مِنَ النِّسَاءِ اللاَّتِي لاَ يَرْجُونَ نِكَاحًا } الآيَةَ .
