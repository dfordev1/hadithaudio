Sunan Abi Dawud · Book 16

Hadith 2817

أَحْمَدُ بْنُ مُحَمَّدِ بْنِ ثَابِتٍ الْمَرْوَزِيُّ ← عَلِيُّ بْنُ حُسَيْنٍ ← أَبِيهِ ← يَزِيدَ النَّحْوِيِّ ← عِكْرِمَةَ ← ابْنِ عَبَّاسٍ { فَكُلُوا مِمَّا ذُكِرَ اسْمُ اللَّهِ عَلَيْهِ } { وَلاَ تَأْكُلُوا مِمَّا لَمْ يُذْكَرِ اسْمُ اللَّهِ عَلَيْهِ } فَنُسِخَ وَاسْتَثْنَى مِنْ ذَلِكَ فَقَالَ { وَطَعَامُ الَّذِينَ أُوتُوا الْكِتَابَ حِلٌّ لَكُمْ وَطَعَامُكُمْ حِلٌّ لَهُمْ } .
