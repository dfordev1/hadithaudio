Sunan Abi Dawud · Book 25

Hadith 3591

عَبْدُ اللَّهِ بْنُ مُحَمَّدٍ النُّفَيْلِيُّ ← مُحَمَّدُ بْنُ سَلَمَةَ ← مُحَمَّدِ بْنِ إِسْحَاقَ ← دَاوُدَ بْنِ الْحُصَيْنِ ← عِكْرِمَةَ ← ابْنِ عَبَّاسٍ لَمَّا نَزَلَتْ هَذِهِ الآيَةُ { فَإِنْ جَاءُوكَ فَاحْكُمْ بَيْنَهُمْ أَوْ أَعْرِضْ عَنْهُمْ } { وَإِنْ حَكَمْتَ فَاحْكُمْ بَيْنَهُمْ بِالْقِسْطِ } الآيَةَ قَالَ كَانَ بَنُو النَّضِيرِ إِذَا قَتَلُوا مِنْ بَنِي قُرَيْظَةَ أَدَّوْا نِصْفَ الدِّيَةِ وَإِذَا قَتَلَ بَنُو قُرَيْظَةَ مِنْ بَنِي النَّضِيرِ أَدَّوْا إِلَيْهِمُ الدِّيَةَ كَامِلَةً فَسَوَّى رَسُولُ اللَّهِ صلى الله عليه وسلم بَيْنَهُمْ .
