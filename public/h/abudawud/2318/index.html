Sunan Abi Dawud · Book 14

Hadith 2318

ابْنُ الْمُثَنَّى ← ابْنُ أَبِي عَدِيٍّ ← سَعِيدٍ ← قَتَادَةَ ← عَزْرَةَ ← سَعِيدِ بْنِ جُبَيْرٍ ← ابْنِ عَبَّاسٍ { وَعَلَى الَّذِينَ يُطِيقُونَهُ فِدْيَةٌ طَعَامُ مِسْكِينٍ } قَالَ كَانَتْ رُخْصَةً لِلشَّيْخِ الْكَبِيرِ وَالْمَرْأَةِ الْكَبِيرَةِ وَهُمَا يُطِيقَانِ الصِّيَامَ أَنْ يُفْطِرَا وَيُطْعِمَا مَكَانَ كُلِّ يَوْمٍ مِسْكِينًا وَالْحُبْلَى وَالْمُرْضِعُ إِذَا خَافَتَا - قَالَ أَبُو دَاوُدَ يَعْنِي عَلَى أَوْلاَدِهِمَا - أَفْطَرَتَا وَأَطْعَمَتَا .
