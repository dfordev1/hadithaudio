Sunan Abi Dawud · Book 40

Hadith 4372

أَحْمَدُ بْنُ مُحَمَّدِ بْنِ ثَابِتٍ ← عَلِيُّ بْنُ حُسَيْنٍ ← أَبِيهِ ← يَزِيدَ النَّحْوِيِّ ← عِكْرِمَةَ ← ابْنِ عَبَّاسٍ { إِنَّمَا جَزَاءُ الَّذِينَ يُحَارِبُونَ اللَّهَ وَرَسُولَهُ وَيَسْعَوْنَ فِي الأَرْضِ فَسَادًا أَنْ يُقَتَّلُوا أَوْ يُصَلَّبُوا أَوْ تُقَطَّعَ أَيْدِيهِمْ وَأَرْجُلُهُمْ مِنْ خِلاَفٍ أَوْ يُنْفَوْا مِنَ الأَرْضِ } إِلَى قَوْلِهِ { غَفُورٌ رَحِيمٌ } نَزَلَتْ هَذِهِ الآيَةُ فِي الْمُشْرِكِينَ فَمَنْ تَابَ مِنْهُمْ قَبْلَ أَنْ يُقْدَرَ عَلَيْهِ لَمْ يَمْنَعْهُ ذَلِكَ أَنْ يُقَامَ فِيهِ الْحَدُّ الَّذِي أَصَابَهُ .
