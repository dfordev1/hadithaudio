Sunan an-Nasa'i · Book 20

Hadith 1700

إِسْحَاقُ بْنُ إِبْرَاهِيمَ أَنْبَأَنَا عِيسَى بْنُ يُونُسَ، عَنْ سَعِيدِ بْنِ أَبِي عَرُوبَةَ، عَنْ قَتَادَةَ، عَنْ سَعِيدِ بْنِ عَبْدِ الرَّحْمَنِ بْنِ أَبْزَى، عَنْ أَبِيهِ، عَنْ أُبَىِّ بْنِ كَعْبٍ، قَالَ كَانَ رَسُولُ اللَّهِ صلى الله عليه وسلم يَقْرَأُ فِي الرَّكْعَةِ الأُولَى مِنَ الْوَتْرِ بِـ { سَبِّحِ اسْمَ رَبِّكَ الأَعْلَى } وَفِي الثَّانِيَةِ بِـ { قُلْ يَا أَيُّهَا الْكَافِرُونَ } وَفِي الثَّالِثَةِ بِـ { قُلْ هُوَ اللَّهُ أَحَدٌ }
