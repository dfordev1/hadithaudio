Sunan an-Nasa'i · Book 37

Hadith 4001

عَمْرُو بْنُ عَلِيٍّ ← يَحْيَى ← ابْنُ جُرَيْجٍ ← الْقَاسِمُ بْنُ أَبِي بَزَّةَ ← سَعِيدِ بْنِ جُبَيْرٍ قُلْتُ لاِبْنِ عَبَّاسٍ هَلْ لِمَنْ قَتَلَ مُؤْمِنًا مُتَعَمِّدًا مِنْ تَوْبَةٍ قَالَ لاَ . وَقَرَأْتُ عَلَيْهِ الآيَةَ الَّتِي فِي الْفُرْقَانِ { وَالَّذِينَ لاَ يَدْعُونَ مَعَ اللَّهِ إِلَهًا آخَرَ وَلاَ يَقْتُلُونَ النَّفْسَ الَّتِي حَرَّمَ اللَّهُ إِلاَّ بِالْحَقِّ } قَالَ هَذِهِ آيَةٌ مَكِّيَّةٌ نَسَخَتْهَا آيَةٌ مَدَنِيَّةٌ { وَمَنْ يَقْتُلْ مُؤْمِنًا مُتَعَمِّدًا فَجَزَاؤُهُ جَهَنَّمُ } .
