Sunan an-Nasa'i · Book 37

Hadith 4007

مُحَمَّدُ بْنُ بَشَّارٍ ← عَبْدِ الْوَهَّابِ ← مُحَمَّدُ بْنُ عَمْرٍو ← مُوسَى بْنِ عُقْبَةَ ← أَبِي الزِّنَادِ ← خَارِجَةَ بْنِ زَيْدٍ ← زَيْدٍ فِي قَوْلِهِ { وَمَنْ يَقْتُلْ مُؤْمِنًا مُتَعَمِّدًا فَجَزَاؤُهُ جَهَنَّمُ } قَالَ نَزَلَتْ هَذِهِ الآيَةُ بَعْدَ الَّتِي فِي { تَبَارَكَ } الْفُرْقَانِ بِثَمَانِيَةِ أَشْهُرٍ { وَالَّذِينَ لاَ يَدْعُونَ مَعَ اللَّهِ إِلَهًا آخَرَ وَلاَ يَقْتُلُونَ النَّفْسَ الَّتِي حَرَّمَ اللَّهُ إِلاَّ بِالْحَقِّ } . قَالَ أَبُو عَبْدِ الرَّحْمَنِ أَدْخَلَ أَبُو الزِّنَادِ بَيْنَهُ وَبَيْنَ خَارِجَةَ مُجَالِدَ بْنَ عَوْفٍ .
