Sunan an-Nasa'i · Book 25

Hadith 3101

نَصْرُ بْنُ عَلِيٍّ ← مُعْتَمِرٌ ← أَبِيهِ ← أَبِي إِسْحَاقَ ← الْبَرَاءِ ← النَّبِيَّ صلى الله عليه وسلم ثُمَّ ذَكَرَ كَلِمَةً مَعْنَاهَا قَالَ " ائْتُونِي بِالْكَتِفِ وَاللَّوْحِ " . فَكَتَبَ { لاَ يَسْتَوِي الْقَاعِدُونَ مِنَ الْمُؤْمِنِينَ } وَعَمْرُو بْنُ أُمِّ مَكْتُومٍ خَلْفَهُ فَقَالَ هَلْ لِي رُخْصَةٌ فَنَزَلَتْ { غَيْرُ أُولِي الضَّرَرِ } .
