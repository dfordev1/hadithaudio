Sunan an-Nasa'i · Book 45

Hadith 4781

الْحَارِثُ بْنُ مِسْكِينٍ قِرَاءَةً عَلَيْهِ وَأَنَا أَسْمَعُ ← سُفْيَانَ ← عَمْرٍو ← مُجَاهِدٍ ← ابْنِ عَبَّاسٍ كَانَ فِي بَنِي إِسْرَائِيلَ الْقِصَاصُ وَلَمْ تَكُنْ فِيهِمُ الدِّيَةُ فَأَنْزَلَ اللَّهُ عَزَّ وَجَلَّ { كُتِبَ عَلَيْكُمُ الْقِصَاصُ فِي الْقَتْلَى الْحُرُّ بِالْحُرِّ وَالْعَبْدُ بِالْعَبْدِ وَالأُنْثَى بِالأُنْثَى } إِلَى قَوْلِهِ { فَمَنْ عُفِيَ لَهُ مِنْ أَخِيهِ شَىْءٌ فَاتِّبَاعٌ بِالْمَعْرُوفِ وَأَدَاءٌ إِلَيْهِ بِإِحْسَانٍ } فَالْعَفْوُ أَنْ يَقْبَلَ الدِّيَةَ فِي الْعَمْدِ وَاتِّبَاعٌ بِمَعْرُوفٍ يَقُولُ يَتَّبِعُ هَذَا بِالْمَعْرُوفِ وَأَدَاءٌ بِإِحْسَانٍ وَيُؤَدِّي هَذَا بِإِحْسَانٍ { ذَلِكَ تَخْفِيفٌ مِنْ رَبِّكُمْ وَرَحْمَةٌ } مِمَّا كُتِبَ عَلَى مَنْ كَانَ قَبْلَكُ
