Sunan an-Nasa'i · Book 11

Hadith 963

مُحَمَّدُ بْنُ مَنْصُورٍ ← سُفْيَانُ ← يَحْيَى بْنِ سَعِيدٍ ← أَبِي بَكْرِ بْنِ مُحَمَّدِ بْنِ عَمْرِو بْنِ حَزْمٍ ← عُمَرَ بْنِ عَبْدِ الْعَزِيزِ ← أَبِي بَكْرِ بْنِ عَبْدِ الرَّحْمَنِ بْنِ الْحَارِثِ بْنِ هِشَامٍ ← أَبِي هُرَيْرَةَ سَجَدْنَا مَعَ النَّبِيِّ صلى الله عليه وسلم فِي { إِذَا السَّمَاءُ انْشَقَّتْ } وَ { اقْرَأْ بِاسْمِ رَبِّكَ }
