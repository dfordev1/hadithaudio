Sunan an-Nasa'i · Book 27

Hadith 3544

قُتَيْبَةُ ← أَبُو الأَحْوَصِ ← سِمَاكٍ ← عِكْرِمَةَ فِي قَوْلِهِ عَزَّ وَجَلَّ { وَالَّذِينَ يُتَوَفَّوْنَ مِنْكُمْ وَيَذَرُونَ أَزْوَاجًا وَصِيَّةً لأَزْوَاجِهِمْ مَتَاعًا إِلَى الْحَوْلِ غَيْرَ إِخْرَاجٍ } قَالَ نَسَخَتْهَا { وَالَّذِينَ يُتَوَفَّوْنَ مِنْكُمْ وَيَذَرُونَ أَزْوَاجًا يَتَرَبَّصْنَ بِأَنْفُسِهِنَّ أَرْبَعَةَ أَشْهُرٍ وَعَشْرًا } .
