Sunan an-Nasa'i · Book 37

Hadith 4002

مُحَمَّدُ بْنُ الْمُثَنَّى ← مُحَمَّدٌ ← شُعْبَةُ ← مَنْصُورٍ ← سَعِيدِ بْنِ جُبَيْرٍ أَمَرَنِي عَبْدُ الرَّحْمَنِ بْنُ أَبِي لَيْلَى أَنْ أَسْأَلَ ابْنَ عَبَّاسٍ، عَنْ هَاتَيْنِ الآيَتَيْنِ، { وَمَنْ يَقْتُلْ مُؤْمِنًا مُتَعَمِّدًا فَجَزَاؤُهُ جَهَنَّمُ } فَسَأَلْتُهُ فَقَالَ لَمْ يَنْسَخْهَا شَىْءٌ . وَعَنْ هَذِهِ الآيَةِ { وَالَّذِينَ لاَ يَدْعُونَ مَعَ اللَّهِ إِلَهًا آخَرَ وَلاَ يَقْتُلُونَ النَّفْسَ الَّتِي حَرَّمَ اللَّهُ إِلاَّ بِالْحَقِّ } قَالَ نَزَلَتْ فِي أَهْلِ الشِّرْكِ .
