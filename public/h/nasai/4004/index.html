Sunan an-Nasa'i · Book 37

Hadith 4004

الْحَسَنُ بْنُ مُحَمَّدٍ الزَّعْفَرَانِيُّ ← حَجَّاجُ بْنُ مُحَمَّدٍ ابْنُ جُرَيْجٍ أَخْبَرَنِي يَعْلَى، عَنْ سَعِيدِ بْنِ جُبَيْرٍ، عَنِ ابْنِ عَبَّاسٍ، أَنَّ نَاسًا، مِنْ أَهْلِ الشِّرْكِ أَتَوْا مُحَمَّدًا فَقَالُوا إِنَّ الَّذِي تَقُولُ وَتَدْعُو إِلَيْهِ لَحَسَنٌ لَوْ تُخْبِرُنَا أَنَّ لِمَا عَمِلْنَا كَفَّارَةً . فَنَزَلَتْ { وَالَّذِينَ لاَ يَدْعُونَ مَعَ اللَّهِ إِلَهًا آخَرَ } وَنَزَلَتْ { قُلْ يَا عِبَادِيَ الَّذِينَ أَسْرَفُوا عَلَى أَنْفُسِهِمْ } .
