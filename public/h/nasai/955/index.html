Sunan an-Nasa'i · Book 11

Hadith 955

مُحَمَّدُ بْنُ بَشَّارٍ ← يَحْيَى بْنُ سَعِيدٍ ← سُفْيَانُ ح وَأَنْبَأَنَا عَمْرُو بْنُ عَلِيٍّ، قَالَ حَدَّثَنَا عَبْدُ الرَّحْمَنِ، قَالَ حَدَّثَنَا سُفْيَانُ، - وَاللَّفْظُ لَهُ - عَنْ سَعْدِ بْنِ إِبْرَاهِيمَ، عَنْ عَبْدِ الرَّحْمَنِ الأَعْرَجِ، عَنْ أَبِي هُرَيْرَةَ، أَنَّ رَسُولَ اللَّهِ صلى الله عليه وسلم كَانَ يَقْرَأُ فِي صَلاَةِ الصُّبْحِ يَوْمَ الْجُمُعَةِ { الم * تَنْزِيلُ } وَ { هَلْ أَتَى }
