Sunan an-Nasa'i · Book 11

Hadith 992

الْفَضْلُ بْنُ سَهْلٍ ← أَبُو الْجَوَّابِ ← عَمَّارُ بْنُ رُزَيْقٍ ← أَبِي إِسْحَاقَ ← إِبْرَاهِيِمَ بْنِ مُهَاجِرٍ ← مُجَاهِدٍ ← ابْنِ عُمَرَ رَمَقْتُ رَسُولَ اللَّهِ صلى الله عليه وسلم عِشْرِينَ مَرَّةً يَقْرَأُ فِي الرَّكْعَتَيْنِ بَعْدَ الْمَغْرِبِ وَفِي الرَّكْعَتَيْنِ قَبْلَ الْفَجْرِ { قُلْ يَا أَيُّهَا الْكَافِرُونَ } وَ { قُلْ هُوَ اللَّهُ أَحَدٌ } .
