Sunan an-Nasa'i · Book 20

Hadith 1702

الْحُسَيْنُ بْنُ عِيسَى ← أَبُو أُسَامَةَ ← زَكَرِيَّا بْنُ أَبِي زَائِدَةَ ← أَبِي إِسْحَاقَ ← سَعِيدِ بْنِ جُبَيْرٍ ← ابْنِ عَبَّاسٍ كَانَ رَسُولُ اللَّهِ صلى الله عليه وسلم يُوتِرُ بِثَلاَثٍ يَقْرَأُ فِي الأُولَى بِـ { سَبِّحِ اسْمَ رَبِّكَ الأَعْلَى } وَفِي الثَّانِيَةِ بِـ { قُلْ يَا أَيُّهَا الْكَافِرُونَ } وَفِي الثَّالِثَةِ بِـ { قُلْ هُوَ اللَّهُ أَحَدٌ } أَوْقَفَهُ زُهَيْرٌ .
