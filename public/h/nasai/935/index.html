Sunan an-Nasa'i · Book 11

Hadith 935

قُتَيْبَةُ ← أَبُو عَوَانَةَ ← مُوسَى بْنِ أَبِي عَائِشَةَ ← سَعِيدِ بْنِ جُبَيْرٍ ← ابْنِ عَبَّاسٍ فِي قَوْلِهِ عَزَّ وَجَلَّ { لاَ تُحَرِّكْ بِهِ لِسَانَكَ لِتَعْجَلَ بِهِ * إِنَّ عَلَيْنَا جَمْعَهُ وَقُرْآنَهُ } قَالَ كَانَ النَّبِيُّ صلى الله عليه وسلم يُعَالِجُ مِنَ التَّنْزِيلِ شِدَّةً وَكَانَ يُحَرِّكُ شَفَتَيْهِ قَالَ اللَّهُ عَزَّ وَجَلَّ { لاَ تُحَرِّكْ بِهِ لِسَانَكَ لِتَعْجَلَ بِهِ * إِنَّ عَلَيْنَا جَمْعَهُ وَقُرْآنَهُ } قَالَ جَمْعَهُ فِي صَدْرِكَ ثُمَّ تَقْرَأَهُ { فَإِذَا قَرَأْنَاهُ فَاتَّبِعْ قُرْآنَهُ } قَالَ فَاسْتَمِعْ لَهُ وَأَنْصِتْ فَكَانَ رَسُولُ اللَّهِ صلى الله عليه وسلم إِذَا أَتَاهُ جِبْرِيلُ اسْتَمَعَ فَإِذَا انْطَلَقَ قَرَأَهُ كَمَا أَقْرَأَهُ .
