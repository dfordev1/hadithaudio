Sunan an-Nasa'i · Book 27

Hadith 3554

زَكَرِيَّا بْنُ يَحْيَى ← إِسْحَاقُ بْنُ إِبْرَاهِيمَ ← عَلِيُّ بْنُ الْحُسَيْنِ بْنِ وَاقِدٍ ← أَبِي ← يَزِيدُ النَّحْوِيُّ ← عِكْرِمَةَ ← ابْنِ عَبَّاسٍ فِي قَوْلِهِ { مَا نَنْسَخْ مِنْ آيَةٍ أَوْ نُنْسِهَا نَأْتِ بِخَيْرٍ مِنْهَا أَوْ مِثْلِهَا } وَقَالَ { وَإِذَا بَدَّلْنَا آيَةً مَكَانَ آيَةٍ وَاللَّهُ أَعْلَمُ بِمَا يُنَزِّلُ } الآيَةَ وَقَالَ { يَمْحُو اللَّهُ مَا يَشَاءُ وَيُثْبِتُ وَعِنْدَهُ أُمُّ الْكِتَابِ } فَأَوَّلُ مَا نُسِخَ مِنَ الْقُرْآنِ الْقِبْلَةُ وَقَالَ { وَالْمُطَلَّقَاتُ يَتَرَبَّصْنَ بِأَنْفُسِهِنَّ ثَلاَثَةَ قُرُوءٍ وَلاَ يَحِلُّ لَهُنَّ أَنْ يَكْتُمْنَ مَا خَلَقَ اللَّهُ فِي أَرْحَامِهِنَّ } إِلَى قَوْلِهِ { إِنْ أَرَادُوا إِصْلاَحًا } وَذَلِكَ بِأَنَّ الرَّجُلَ كَ
