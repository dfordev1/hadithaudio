Sunan an-Nasa'i · Book 20

Hadith 1732

عَمْرُو بْنُ يَزِيدَ ← بَهْزُ بْنُ أَسَدٍ ← شُعْبَةُ ← سَلَمَةَ وَزُبَيْدٍ، عَنْ ذَرٍّ، عَنِ ابْنِ عَبْدِ الرَّحْمَنِ بْنِ أَبْزَى، عَنْ أَبِيهِ، أَنَّ رَسُولَ اللَّهِ صلى الله عليه وسلم كَانَ يُوتِرُ بِـ { سَبِّحِ اسْمَ رَبِّكَ الأَعْلَى } وَ { قُلْ يَا أَيُّهَا الْكَافِرُونَ } وَ { قُلْ هُوَ اللَّهُ أَحَدٌ } وَكَانَ يَقُولُ إِذَا سَلَّمَ " سُبْحَانَ الْمَلِكِ الْقُدُّوسِ " . ثَلاَثًا وَيَرْفَعُ صَوْتَهُ بِالثَّالِثَةِ .
