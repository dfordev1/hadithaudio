Sunan an-Nasa'i · Book 11

Hadith 989

مُحَمَّدُ بْنُ سَلَمَةَ ← ابْنُ وَهْبٍ ← عَمْرِو بْنِ الْحَارِثِ ← أَبِي الأَسْوَدِ أَنَّهُ سَمِعَ عُرْوَةَ بْنَ الزُّبَيْرِ، يُحَدِّثُ عَنْ زَيْدِ بْنِ ثَابِتٍ، أَنَّهُ قَالَ لِمَرْوَانَ يَا أَبَا عَبْدِ الْمَلِكِ أَتَقْرَأُ فِي الْمَغْرِبِ بِـ { قُلْ هُوَ اللَّهُ أَحَدٌ } وَ { إِنَّا أَعْطَيْنَاكَ الْكَوْثَرَ } قَالَ نَعَمْ . قَالَ فَمَحْلُوفَةٌ لَقَدْ رَأَيْتُ رَسُولَ اللَّهِ صلى الله عليه وسلم يَقْرَأُ فِيهَا بِأَطْوَلِ الطُّولَيَيْنِ { المص } .
