Sunan an-Nasa'i · Book 11

Hadith 997

مُحَمَّدُ بْنُ قُدَامَةَ ← جَرِيرٌ ← الأَعْمَشِ ← مُحَارِبِ بْنِ دِثَارٍ ← جَابِرٍ قَامَ مُعَاذٌ فَصَلَّى الْعِشَاءَ الآخِرَةَ فَطَوَّلَ فَقَالَ النَّبِيُّ صلى الله عليه وسلم " أَفَتَّانٌ يَا مُعَاذُ أَفَتَّانٌ يَا مُعَاذُ أَيْنَ كُنْتَ عَنْ { سَبِّحِ اسْمَ رَبِّكَ الأَعْلَى } وَالضُّحَى وَ { إِذَا السَّمَاءُ انْفَطَرَتْ } " .
