Sunan an-Nasa'i · Book 20

Hadith 1739

عَبْدُ اللَّهِ بْنُ الصَّبَّاحِ ← الْحَسَنُ بْنُ حَبِيبٍ ← رَوْحُ بْنُ الْقَاسِمِ ← عَطَاءِ بْنِ السَّائِبِ ← سَعِيدِ بْنِ عَبْدِ الرَّحْمَنِ بْنِ أَبْزَى ← أَبِيهِ ← رَسُولَ اللَّهِ صلى الله عليه وسلم كَانَ يَقْرَأُ فِي الْوِتْرِ بِـ { سَبِّحِ اسْمَ رَبِّكَ الأَعْلَى } وَ { قُلْ يَا أَيُّهَا الْكَافِرُونَ } وَ { قُلْ هُوَ اللَّهُ أَحَدٌ }
