Sunan an-Nasa'i · Book 24

Hadith 2963

عَمْرُو بْنُ عُثْمَانَ بْنِ سَعِيدِ بْنِ كَثِيرِ بْنِ دِينَارٍ الْحِمْصِيُّ ← الْوَلِيدِ ← مَالِكٍ ← جَعْفَرِ بْنِ مُحَمَّدٍ ← أَبِيهِ ← جَابِرِ بْنِ عَبْدِ اللَّهِ ← رَسُولَ اللَّهِ صلى الله عليه وسلم لَمَّا انْتَهَى إِلَى مَقَامِ إِبْرَاهِيمَ قَرَأَ { وَاتَّخِذُوا مِنْ مَقَامِ إِبْرَاهِيمَ مُصَلًّى } فَصَلَّى رَكْعَتَيْنِ فَقَرَأَ فَاتِحَةَ الْكِتَابِ وَ { قُلْ يَا أَيُّهَا الْكَافِرُونَ } وَ { قُلْ هُوَ اللَّهُ أَحَدٌ } ثُمَّ عَادَ إِلَى الرُّكْنِ فَاسْتَلَمَهُ ثُمَّ خَرَجَ إِلَى الصَّفَا .
