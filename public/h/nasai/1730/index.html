Sunan an-Nasa'i · Book 20

Hadith 1730

يَحْيَى بْنُ مُوسَى ← عَبْدُ الرَّحْمَنِ بْنُ عَبْدِ اللَّهِ بْنِ سَعْدٍ ← أَبُو جَعْفَرٍ الرَّازِيُّ ← الأَعْمَشِ ← زُبَيْدٍ وَطَلْحَةَ، عَنْ ذَرٍّ، عَنْ سَعِيدِ بْنِ عَبْدِ الرَّحْمَنِ بْنِ أَبْزَى، عَنْ أَبِيهِ، عَنْ أُبَىِّ بْنِ كَعْبٍ، قَالَ كَانَ رَسُولُ اللَّهِ صلى الله عليه وسلم يُوتِرُ بِـ { سَبِّحِ اسْمَ رَبِّكَ الأَعْلَى } وَ { قُلْ يَا أَيُّهَا الْكَافِرُونَ } وَ { قُلْ هُوَ اللَّهُ أَحَدٌ } خَالَفَهُمَا حُصَيْنٌ فَرَوَاهُ عَنْ ذَرٍّ عَنِ ابْنِ عَبْدِ الرَّحْمَنِ بْنِ أَبْزَى عَنْ أَبِيهِ عَنِ النَّبِيِّ صلى الله عليه وسلم .
