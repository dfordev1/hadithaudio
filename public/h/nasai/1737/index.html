Sunan an-Nasa'i · Book 20

Hadith 1737

أَحْمَدُ بْنُ مُحَمَّدِ بْنِ عُبَيْدِ اللَّهِ ← شُعَيْبُ بْنُ حَرْبٍ ← مَالِكٍ ← زُبَيْدٍ ← ابْنِ أَبْزَى ← أَبِيهِ كَانَ رَسُولُ اللَّهِ صلى الله عليه وسلم يَقْرَأُ فِي الْوِتْرِ بِـ { سَبِّحِ اسْمَ رَبِّكَ الأَعْلَى } وَ { قُلْ يَا أَيُّهَا الْكَافِرُونَ } وَ { قُلْ هُوَ اللَّهُ أَحَدٌ } .
