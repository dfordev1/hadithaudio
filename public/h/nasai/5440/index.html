Sunan an-Nasa'i · Book 50

Hadith 5440

مُحَمَّدُ بْنُ الْمُثَنَّى ← يَحْيَى ← إِسْمَاعِيلُ ← قَيْسٌ ← عُقْبَةَ بْنِ عَامِرٍ ← النَّبِيِّ صلى الله عليه وسلم " أُنْزِلَ عَلَىَّ آيَاتٌ لَمْ يُرَ مِثْلُهُنَّ { قُلْ أَعُوذُ بِرَبِّ الْفَلَقِ } إِلَى آخِرِ السُّورَةِ وَ { قُلْ أَعُوذُ بِرَبِّ النَّاسِ } " . إِلَى آخِرِ السُّورَةِ .
