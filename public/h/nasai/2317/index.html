Sunan an-Nasa'i · Book 22

Hadith 2317

مُحَمَّدُ بْنُ إِسْمَاعِيلَ بْنِ إِبْرَاهِيمَ ← يَزِيدُ أَنْبَأَنَا وَرْقَاءُ، عَنْ عَمْرِو بْنِ دِينَارٍ، عَنْ عَطَاءٍ، عَنِ ابْنِ عَبَّاسٍ، فِي قَوْلِهِ عَزَّ وَجَلَّ { وَعَلَى الَّذِينَ يُطِيقُونَهُ فِدْيَةٌ طَعَامُ مِسْكِينٍ } يُطِيقُونَهُ يُكَلَّفُونَهُ فِدْيَةٌ طَعَامُ مِسْكِينٍ وَاحِدٍ { فَمَنْ تَطَوَّعَ خَيْرًا } طَعَامُ مِسْكِينٍ آخَرَ لَيْسَتْ بِمَنْسُوخَةٍ { فَهُوَ خَيْرٌ لَهُ وَأَنْ تَصُومُوا خَيْرٌ لَكُمْ } لاَ يُرَخَّصُ فِي هَذَا إِلاَّ لِلَّذِي لاَ يُطِيقُ الصِّيَامَ أَوْ مَرِيضٍ لاَ يُشْفَى .
