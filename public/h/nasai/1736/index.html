Sunan an-Nasa'i · Book 20

Hadith 1736

عِمْرَانُ بْنُ مُوسَى ← عَبْدُ الْوَارِثِ ← مُحَمَّدُ بْنُ جُحَادَةَ ← زُبَيْدٍ ← ابْنِ أَبْزَى ← أَبِيهِ كَانَ رَسُولُ اللَّهِ صلى الله عليه وسلم يُوتِرُ بِـ { سَبِّحِ اسْمَ رَبِّكَ الأَعْلَى } وَ { قُلْ يَا أَيُّهَا الْكَافِرُونَ } وَ { قُلْ هُوَ اللَّهُ أَحَدٌ } فَإِذَا فَرَغَ مِنَ الصَّلاَةِ قَالَ " سُبْحَانَ الْمَلِكِ الْقُدُّوسِ " . ثَلاَثَ مَرَّاتٍ .
