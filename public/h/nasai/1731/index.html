Sunan an-Nasa'i · Book 20

Hadith 1731

الْحَسَنُ بْنُ قَزَعَةَ ← حُصَيْنِ بْنِ نُمَيْرٍ ← حُصَيْنِ بْنِ عَبْدِ الرَّحْمَنِ ← ذَرٍّ ← ابْنِ عَبْدِ الرَّحْمَنِ بْنِ أَبْزَى ← أَبِيهِ ← رَسُولَ اللَّهِ صلى الله عليه وسلم كَانَ يَقْرَأُ فِي الْوِتْرِ بِـ { سَبِّحِ اسْمَ رَبِّكَ الأَعْلَى } وَ { قُلْ يَا أَيُّهَا الْكَافِرُونَ } وَ { قُلْ هُوَ اللَّهُ أَحَدٌ }
