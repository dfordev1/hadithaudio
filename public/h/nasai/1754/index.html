Sunan an-Nasa'i · Book 20

Hadith 1754

مُحَمَّدُ بْنُ الْمُثَنَّى ← عَبْدُ الْعَزِيزِ بْنُ عَبْدِ الصَّمَدِ ← سَعِيدٌ ← قَتَادَةَ ← عَزْرَةَ ← سَعِيدِ بْنِ عَبْدِ الرَّحْمَنِ بْنِ أَبْزَى ← أَبِيهِ ← رَسُولَ اللَّهِ صلى الله عليه وسلم كَانَ يُوتِرُ بِـ { سَبِّحِ اسْمَ رَبِّكَ الأَعْلَى } وَ { قُلْ يَا أَيُّهَا الْكَافِرُونَ } وَ { قُلْ هُوَ اللَّهُ أَحَدٌ } وَإِذَا فَرَغَ قَالَ " سُبْحَانَ الْمَلِكِ الْقُدُّوسِ " . أَرْسَلَهُ هِشَامٌ .
