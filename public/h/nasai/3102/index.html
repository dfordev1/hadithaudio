Sunan an-Nasa'i · Book 25

Hadith 3102

مُحَمَّدُ بْنُ عُبَيْدٍ ← أَبُو بَكْرِ بْنُ عَيَّاشٍ ← أَبِي إِسْحَاقَ ← الْبَرَاءِ لَمَّا نَزَلَتْ { لاَ يَسْتَوِي الْقَاعِدُونَ مِنَ الْمُؤْمِنِينَ } جَاءَ ابْنُ أُمِّ مَكْتُومٍ وَكَانَ أَعْمَى فَقَالَ يَا رَسُولَ اللَّهِ فَكَيْفَ فِيَّ وَأَنَا أَعْمَى قَالَ فَمَا بَرِحَ حَتَّى نَزَلَتْ { غَيْرُ أُولِي الضَّرَرِ } .
