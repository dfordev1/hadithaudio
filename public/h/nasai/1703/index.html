Sunan an-Nasa'i · Book 20

Hadith 1703

أَحْمَدُ بْنُ سُلَيْمَانَ ← أَبُو نُعَيْمٍ ← زُهَيْرٌ ← أَبِي إِسْحَاقَ ← سَعِيدِ بْنِ جُبَيْرٍ ← ابْنِ عَبَّاسٍ أَنَّهُ كَانَ يُوتِرُ بِثَلاَثٍ بِـ { سَبِّحِ اسْمَ رَبِّكَ الأَعْلَى } وَ { قُلْ يَا أَيُّهَا الْكَافِرُونَ } وَ { قُلْ هُوَ اللَّهُ أَحَدٌ }
