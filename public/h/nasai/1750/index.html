Sunan an-Nasa'i · Book 20

Hadith 1750

أَحْمَدُ بْنُ حَرْبٍ ← قَاسِمٌ ← سُفْيَانَ ← زُبَيْدٍ ← سَعِيدِ بْنِ عَبْدِ الرَّحْمَنِ بْنِ أَبْزَى ← أَبِيهِ ← النَّبِيِّ صلى الله عليه وسلم أَنَّهُ كَانَ يُوتِرُ بِـ { سَبِّحِ اسْمَ رَبِّكَ الأَعْلَى } وَ { قُلْ يَا أَيُّهَا الْكَافِرُونَ } وَ { قُلْ هُوَ اللَّهُ أَحَدٌ } وَيَقُولُ بَعْدَ مَا يُسَلِّمُ " سُبْحَانَ الْمَلِكِ الْقُدُّوسِ " . ثَلاَثَ مَرَّاتٍ يَرْفَعُ بِهَا صَوْتَهُ .
