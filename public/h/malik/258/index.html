Muwatta Malik · Book 7

Hadith 258

مَالِكٍ ← زَيْدِ بْنِ أَسْلَمَ ← أَبِيهِ ← عُمَرَ بْنَ الْخَطَّابِ كَانَ يُصَلِّي مِنَ اللَّيْلِ مَا شَاءَ اللَّهُ حَتَّى إِذَا كَانَ مِنْ آخِرِ اللَّيْلِ أَيْقَظَ أَهْلَهُ لِلصَّلاَةِ يَقُولُ لَهُمُ الصَّلاَةَ الصَّلاَةَ ثُمَّ يَتْلُو هَذِهِ الآيَةَ { وَأْمُرْ أَهْلَكَ بِالصَّلاَةِ وَاصْطَبِرْ عَلَيْهَا لاَ نَسْأَلُكَ رِزْقًا نَحْنُ نَرْزُقُكَ وَالْعَاقِبَةُ لِلتَّقْوَى }
