Muwatta Malik · Book 20

Hadith 874

مَالِكٍ ← هِشَامِ بْنِ عُرْوَةَ ← عَبْدِ اللَّهِ بْنِ الزُّبَيْرِ كَانَ يَقُولُ اعْلَمُوا أَنَّ عَرَفَةَ كُلَّهَا مَوْقِفٌ إِلاَّ بَطْنَ عُرَنَةَ وَأَنَّ الْمُزْدَلِفَةَ كُلَّهَا مَوْقِفٌ إِلاَّ بَطْنَ مُحَسِّرٍ . قَالَ مَالِكٌ قَالَ اللَّهُ تَبَارَكَ وَتَعَالَى { فَلاَ رَفَثَ وَلاَ فُسُوقَ وَلاَ جِدَالَ فِي الْحَجِّ } قَالَ فَالرَّفَثُ إِصَابَةُ النِّسَاءِ وَاللَّهُ أَعْلَمُ قَالَ اللَّهُ تَبَارَكَ وَتَعَالَى { أُحِلَّ لَكُمْ لَيْلَةَ الصِّيَامِ الرَّفَثُ إِلَى نِسَائِكُمْ } قَالَ وَالْفُسُوقُ الذَّبْحُ لِلأَنْصَابِ وَاللَّهُ أَعْلَمُ قَالَ اللَّهُ تَبَارَكَ وَتَعَالَى { أَوْ فِسْقًا أُهِلَّ لِغَيْرِ اللَّهِ بِهِ } . قَالَ وَالْجِدَالُ فِي الْحَجِّ أَنَّ قُرَيْشًا كَانَتْ تَقِفُ عِنْدَ الْم
