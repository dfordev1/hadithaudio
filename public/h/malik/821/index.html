Muwatta Malik · Book 20

Hadith 821

يَحْيَى ← مَالِكٍ ← نَافِعٍ ← عَبْدِ اللَّهِ بْنِ عُمَرَ ← عُمَرَ بْنَ الْخَطَّابِ لاَ يَصْدُرَنَّ أَحَدٌ مِنَ الْحَاجِّ حَتَّى يَطُوفَ بِالْبَيْتِ فَإِنَّ آخِرَ النُّسُكِ الطَّوَافُ بِالْبَيْتِ . قَالَ مَالِكٌ فِي قَوْلِ عُمَرَ بْنِ الْخَطَّابِ فَإِنَّ آخِرَ النُّسُكِ الطَّوَافُ بِالْبَيْتِ إِنَّ ذَلِكَ - فِيمَا نُرَى وَاللَّهُ أَعْلَمُ - لِقَوْلِ اللَّهِ تَبَارَكَ وَتَعَالَى { وَمَنْ يُعَظِّمْ شَعَائِرَ اللَّهِ فَإِنَّهَا مِنْ تَقْوَى الْقُلُوبِ } وَقَالَ { ثُمَّ مَحِلُّهَا إِلَى الْبَيْتِ الْعَتِيقِ } فَمَحِلُّ الشَّعَائِرِ كُلِّهَا وَانْقِضَاؤُهَا إِلَى الْبَيْتِ الْعَتِيقِ
