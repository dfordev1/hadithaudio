Jami at-Tirmidhi · Book 47

Hadith 3316

عَبْدُ بْنُ حُمَيْدٍ ← جَعْفَرُ بْنُ عَوْنٍ ← أَبُو جَنَابٍ الْكَلْبِيُّ ← الضَّحَّاكِ بْنِ مُزَاحِمٍ ← ابْنِ عَبَّاسٍ رضى الله عنهما قَالَ مَنْ كَانَ لَهُ مَالٌ يُبَلِّغُهُ حَجَّ بَيْتِ رَبِّهِ أَوْ تَجِبُ عَلَيْهِ فِيهِ الزَّكَاةُ فَلَمْ يَفْعَلْ سَأَلَ الرَّجْعَةَ عِنْدَ الْمَوْتِ . فَقَالَ رَجُلٌ يَا ابْنَ عَبَّاسٍ اتَّقِ اللَّهَ إِنَّمَا سَأَلَ الرَّجْعَةَ الْكُفَّارُ قَالَ سَأَتْلُو عَلَيْكَ بِذَلِكَ قُرْآنًا : ( يا أَيُّهَا الَّذِينَ آمَنُوا لاَ تُلْهِكُمْ أَمْوَالُكُمْ وَلاَ أَوْلاَدُكُمْ عَنْ ذِكْرِ اللَّهِ ) : (وأَنْفِقُوا مِمَّا رَزَقْنَاكُمْ مِنْ قَبْلِ أَنْ يَأْتِيَ أَحَدَكُمُ الْمَوْتُ ) إِلَى قَوْلِهِ : ( واللَّهُ خَبِيرٌ بِمَا تَعْمَلُونَ ) قَالَ فَمَا يُوجِبُ الزَّكَاةَ قَال
