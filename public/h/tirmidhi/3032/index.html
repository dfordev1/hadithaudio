Jami at-Tirmidhi · Book 47

Hadith 3032

الْحَسَنُ بْنُ مُحَمَّدٍ الزَّعْفَرَانِيُّ ← الْحَجَّاجُ بْنُ مُحَمَّدٍ ← ابْنِ جُرَيْجٍ ← عَبْدُ الْكَرِيمِ سَمِعَ مِقْسَمًا، مَوْلَى عَبْدِ اللَّهِ بْنِ الْحَارِثِ يُحَدِّثُ عَنِ ابْنِ عَبَّاسٍ، أَنَّهُ قَالَ : ( لَا يَسْتَوِي الْقَاعِدُونَ مِنَ الْمُؤْمِنِينَ غَيْرُ أُولِي الضَّرَرِ ) عَنْ بَدْرٍ وَالْخَارِجُونَ إِلَى بَدْرٍ لَمَّا نَزَلَتْ غَزْوَةُ بَدْرٍ قَالَ عَبْدُ اللَّهِ بْنُ جَحْشٍ وَابْنُ أُمِّ مَكْتُومٍ إِنَّا أَعْمَيَانِ يَا رَسُولَ اللَّهِ فَهَلْ لَنَا رُخْصَةٌ فَنَزَلَتْ : ( لَا يَسْتَوِي الْقَاعِدُونَ مِنَ الْمُؤْمِنِينَ غَيْرُ أُولِي الضَّرَرِ ) و : (فَضَّلَ اللَّهُ الْمُجَاهِدِينَ عَلََى الْقَاعِدِينَ دَرَجَةً ) فَهَؤُلاَءِ الْقَاعِدُونَ غَيْرُ أُولِي الضَّرَرِ : ( وَفَضَّل
