# Hadith text cutoff audit

## Ibn Khuzaymah

Screened all 3,282 records in the published Git corpus, including all 14 word timing files. In 3,004 records with audio, the timing file has fewer entries than the whitespace-separated written text. This is a coverage signal, not a count of confirmed omissions. Punctuation, differences in segmentation, and legitimate differences between the recording and written edition affect the count.

Written records ending with an ellipsis: 1978, 2719. Report 2719 follows the fuller parallel report 2718. Check the edition before expanding any abbreviated variant. Report 1978 corresponds to printed report 1771 in the Friday prayer section. Report 1 now reaches the written narrator's summary of the remaining questions about faith, excellence, and the Hour.

Written records whose body ends with a speech verb and need edition comparison: 383, 401, 443, 482, 485, 486, 487, 706, 762, 928, 1243, 1556, 1926, 1955, 2013, 2014, 2127. These are review candidates, not confirmed omissions. In particular, 1243 ends in «فقال: قال».

## Other collections

The same reader substituted sidecar tokens for written tokens in Bukhari, Muslim, Abu Dawud, Tirmidhi, Nasa'i, Ibn Majah, Muwatta Malik, Riyad as-Salihin, and Musnad Ahmad. The reader now uses the written tokens when available and maps timestamps onto matching words. This resolves the shared rendering path, without certifying the edition data or assessing every recording. Collections whose packages carry only one token stream require a separate edition comparison to detect upstream omissions.
